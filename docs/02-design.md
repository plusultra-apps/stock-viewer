## 1. 한눈에

- **화면 1개**: 왼쪽 종목 목록(검색창 포함) + 오른쪽 차트. PC 1280px 기준. 폭 900px 미만에서는 목록이 위로 쌓인다.
- **상태 11개** (`?state=` 로 전부 본다): 정상 · 로딩 · 빈 목록 · 검색 결과 없음 · 요청 제한 · 종목 목록 실패 · 차단(451) · 재연결 중 · 연결 끊김 · 거래 종료 · 봉 로드 실패.
- **보는 법**: `design/chart-only.html` 을 브라우저로 연다. 화면 아래 "시안 상태 보기" 줄을 누르면 상태가 바뀐다. 간격 버튼·목록 클릭·검색 입력은 실제로 동작한다 (예시 데이터 안에서만).
- **시작 상태**: BTCUSDT, 1분봉 (PR/FAQ "시작하는 법"). 기존 chart-only 는 1시간봉으로 열렸으나 기획에 맞춰 1분봉으로 바꿨다.
- **색**: 상승 초록 · 하락 빨강 (기존 chart-only 와 같다. 사용자 결정 반영). 이전 문서의 "A/B 색 질문"은 닫는다.
- **기존 chart-only 에서 유지한 것**: 차트 모양(캔들·거래량·현재가 점선·오른쪽 가격 눈금), 간격 버튼 6개와 눌림 표시, 색, KST 표시, 바닥 문구.

## 2. 화면 구성과 흐름

### 화면 구성 (정상 상태, PC 1280px)

```
+-----------------------------------------------------------------------------+
| 선물 종목 실시간 캔들 차트 [예시 데이터 · 학습용 시안]   시세 조회 전용 · KST  |  ← 상단 바
+-----------------------------------------------------------------------------+
| (상태 알림 줄: 재연결 중 / 끊김 / 요청 제한 / 차단 / 목록 실패 때만)           |  ← role=status
+------------------------------+----------------------------------------------+
| [ 기호 일부 입력 (btc, pepe) ]| BTCUSDT  USDⓈ-M 무기한 선물  ( ● 실시간 )     |
| 종목 5개 · 거래대금 순        | 93,412.50          ▲ +0.44% (24시간)  마지막 갱신 |
|------------------------------|----------------------------------------------|
| BTCUSDT          93,412.50   | [1분][5분][15분][1시간][4시간][1일]  ← 눌림 강조   |
| 거래대금 $18.4B  ▲ +0.44%    | BTCUSDT · 1분봉                               |
|------------------------------| +------------------------------------------+  |
| ETHUSDT           3,520.15   | |  캔들 + 현재가 점선 (오른쪽 가격 눈금)    |  |
| 거래대금 $9.7B   ▼ -1.12%    | |  거래량 막대 (아래)                       |  |
|------------------------------| |  시간 눈금 (KST)                  KST     |  |
| 1000PEPEUSDT      0.01234    | +------------------------------------------+  |
| 거래대금 $1.6B · 1000배 단위  | 진행 중 봉 · 시 · 고 · 저 · 종 · 거래량         |
| ...  (행 전부, 스크롤)         |                                              |
+------------------------------+----------------------------------------------+
| 시세 조회 전용. 주문·로그인·API 키 입력 없음. 시간 KST.                         |
+-----------------------------------------------------------------------------+
```

- 목록 행(56px): 1줄 기호 · 현재가, 2줄 거래대금 · 24시간 등락률. 선택된 행은 배경 + 왼쪽 노란 막대.
- 헤더: 선택 종목 기호, 현재가(큰 글씨), 24시간 등락률 (목록과 같은 값), 마지막 갱신 시각(KST).
- 마우스를 봉에 올리면 말풍선: 시각(KST), 시가·고가·저가·종가, 거래량. 아래 한 줄도 같은 값으로 바뀐다 (터치·키보드용 대체는 설계 단계).
- 종목이 1000 단위 기호(예: `1000PEPEUSDT`)면 헤더와 행에 "1000배 단위 종목" 안내를 붙였다 (열린 질문 1).

### 흐름

```
열기 ──▶ [로딩] ──(목록·봉 도착)──▶ [정상 · 실시간]  (기본 BTCUSDT 1분봉, 목록은 거래대금 큰 순)
                                       │
          ┌────────────────────────────┼─────────────────────────────┐
          ▼                            ▼                             ▼
 검색창 입력 (AC14)            목록 종목 누르기 (AC15)         간격 버튼 누르기 (AC2)
 기호 포함 일치로 목록 필터     차트가 그 종목 봉으로 교체,      같은 종목 봉을 그 간격으로 다시 그림
 0건 → [검색 결과 없음]        간격은 그대로 유지             (모든 상태에서 누를 수 있다)
 지우면 전체 목록 복귀
```

- 시안의 버튼("다시 시도", "다시 연결", 목록 항목)을 누르면 **정상 화면으로 돌아간다**. 실제 상태 전이(재시도 횟수, 대기 시간 줄어들기 등)는 설계 단계에서 다룬다.
- 목록을 누르면 이전 종목 봉은 지우고 새 종목 봉만 그린다 (AC15, AC16의 화면 면).

## 3. 상태 표

| 상태 | `?state=` | 목록 영역 | 차트 영역 | 상단 알림 · 칩 | 대응 AC |
|---|---|---|---|---|---|
| 정상 (실시간) | `live` | 종목 행 전부, 거래대금 순, 선택 행 강조 | 캔들·거래량·현재가 점선, 말풍선, 간격 눌림 | 알림 없음 · 칩 "실시간" | AC1, AC2, AC5, AC13, AC14, AC15, AC17 |
| 로딩 | `loading` | "종목 목록을 불러오는 중…" + 회색 행 6개 | "봉을 불러오는 중…" 회색 그림 | 칩 "연결 중…" | AC1 (5초 안에 바뀌어야 함. 넘기면 실패) |
| 빈 목록 | `empty` | "거래 중인 무기한 선물 종목이 없습니다" (검색 비활성) | "표시할 종목이 없습니다" | 칩 "종목 없음" | AC13 (목록 0개 경우). 기획 AC 밖 정상 응답 케이스 |
| 검색 결과 없음 | `nomatch` | 검색어 `zzzz` 로 "검색 결과 없음", "검색어를 지우면 전체 목록이 나옵니다" | 현재 종목 차트 유지 | 칩 "실시간" | AC14 (`zzzz`) |
| 요청 제한 | `ratelimit` | 행은 **멈춘 값** ("· 멈춤"), 목록 그대로 보임 | 멈춘 차트 (유지) | 노란 알림 "요청이 너무 많아 잠시 후 다시 시도합니다. 남은 대기 약 45초" · 칩 "요청 제한" | AC21 |
| 종목 목록 실패 | `listerror` | "종목 목록을 불러오지 못했습니다" + [다시 시도] (행 없음, 검색 비활성) | 선택 종목 차트는 계속 보임 | 주황 알림 + [다시 시도] · 칩 "목록 실패" | AC13·AC9 의 실패 경로. 기획 AC 에는 없음 (추가 상태, 열린 질문 없음) |
| 차단 (오류 451) | `blocked` | "시세를 받을 수 없습니다 (오류 451)" (행 없음) | "차트를 표시할 수 없습니다 (오류 451)", 가격 "--" | 주황 알림 "이 지역/네트워크에서는 시세를 받을 수 없습니다 (오류 451). 가격과 차트를 표시하지 않습니다." · 칩 "시세 차단" | AC9 (목록도 포함) |
| 재연결 중 | `reconnecting` | 행 값이 멈춤 ("· 멈춤") | 차트 멈춤, 마지막 봉 "마지막 봉 · 멈춤" | 노란 알림 "연결이 끊겨 다시 연결하고 있습니다 (3회 시도)…" · 칩 "재연결 중" | AC6 (5초 안에 표시, 마지막 갱신 시각), AC7 (복귀는 정상과 같음) |
| 연결 끊김 (복구 실패) | `offline` | 행 멈춤 | 차트 흐리게 (불투명도 50%) | 주황 알림 "연결을 복구하지 못했습니다. 마지막 값 14:03:12 KST 기준입니다." + [다시 연결] · 칩 "연결 끊김" | AC6 (끊김 표시 경우) |
| 거래 종료 | `delisted` | 보던 종목 `OLDCOINUSDT` 는 **목록에 없음**. 나머지 행 정상 | 마지막 봉까지 남김, 실시간 갱신 멈춤 | 주황 알림 "이 종목은 거래가 종료/정지되었습니다. 마지막 봉은 남기고 실시간 갱신을 멈췄습니다." · 칩 "거래 종료" | AC18 (10초 안 표시, 다른 종목 선택 가능) |
| 봉 로드 실패 | `candleerror` | 정상 (`EXAMPLEUSDT` 선택 표시) | "이 종목의 봉을 불러오지 못했습니다" + [다시 시도] | 알림 없음 · 칩 "봉 실패" | AC22 (다른 종목을 눌러 복구) |

- 칩과 알림은 **색 + 글자**로 함께 알린다 (색만으로 구분하지 않는다).
- 목록 상태와 차트 상태는 따로 움직인다. 예: 목록은 정상인데 차트만 실패할 수 있다 (`candleerror`).
- 검색창은 목록이 정상(행 표시)일 때만 입력할 수 있다. 나머지 상태에서는 흐리게 비활성.

## 4. AC 대응표 (AC1~AC22)

"시안에서 보이는 것"은 화면에서 확인 가능한 범위만 적었다. "설계·시험에서 확인"은 데이터 동작이라 시안으로는 증명할 수 없는 부분이다.

| AC | 화면 위치 | 시안에서 보이는 것 | 설계·시험에서 확인할 것 |
|---|---|---|---|
| AC1 | 목록 + 차트 첫 화면 | 기본 BTCUSDT 1분봉, 캔들 + 거래량 (시안은 100개, 기획은 500개) | 5초 안에 목록·차트 도착, 500개 렌더 |
| AC2 | 간격 버튼 6개 | 눌린 간격 강조(글자 굵게 + 배경 + 아래 밑줄). 간격 바꾸면 봉이 다시 그려짐 | 3초 안 반영, 종목 바꿔도 간격 유지 (시안은 유지되어 보임) |
| AC3 | 헤더 현재가 + 차트 마지막 봉 | 현재가·마지막 봉 종가 표시 | 5초 안 움직임 (데이터 동작, 시안 정지) |
| AC4 | 차트 | 시안 없음 (데이터 동작) | 봉 닫힘 시 연속 추가, 중복·누락 없음 |
| AC5 | 차트 말풍선 | 마우스 올리면 KST 시각, 시·고·저·종, 거래량 | REST 5개 봉과 대조, KST 확인 |
| AC6 | 상단 알림 + 멈춤 표시 | `reconnecting` 상태 (노란 알림, 멈춘 값, 마지막 갱신 시각) | 네트워크 끄고 5초 안 표시 |
| AC7 | 알림 사라짐 | 시안 없음 (정상 화면과 같음) | 복귀 30초, 빠진 봉 채움 |
| AC8 | 차트 | 시안 없음 (데이터) | 3종목 닫힌 봉 10개 대조 |
| AC9 | 목록 + 차트 + 알림 | `blocked` 상태 (목록·차트·알림 모두 이유 문구) | 모의 응답으로 451 시험 |
| AC10 | 화면 전체 | 주문·로그인·API 키 칸이 **없다** (화면 어디에도) | 네트워크 탭에서 인증 요청 없음 |
| AC11 | 전체 | 시안 없음 | 1시간 관찰, 종목 전환 1회 포함 |
| AC12 | 전체, 1280px | 1280px 폭에서 목록(340px) + 차트가 잘리지 않음 | 브라우저 창 크기 확인 (시안 열어 확인 가능) |
| AC13 | 목록 | 행: 기호·현재가·거래대금·24시간 등락률. 상한 없이 전부 스크롤 | 행 수 = REST 거래 중 무기한 종목 수 |
| AC14 | 검색창 + 목록 필터 | 입력 즉시 포함 일치로 필터. `pepe` → `1000PEPEUSDT`, `btc` → `BTCUSDT`, `zzzz` → 검색 결과 없음, 빈 값 → 전체 | 입력 후 0.5초 안 반응 (시안은 즉시) |
| AC15 | 헤더 기호 · 차트 제목 · 자릿수 | `BTCUSDT`(93,412.50) → `1000PEPEUSDT`(0.01234) 로 바꾸면 자릿수·차트가 바뀜. 이전 봉 남지 않음 | 3초 안 전환, 이전 값이 남지 않음 |
| AC16 | 없음 | 시안 없음 (화면 면은 "차트 1개") | 개발자 도구 WebSocket 연결 수 = 1 |
| AC17 | 목록 행 | 행의 현재가·등락률 값 (시안 값은 고정) | 5초 안 갱신, 바이낸스 앱과 대조 |
| AC18 | 목록 빠짐 + 차트 알림 | `delisted`: 보던 종목이 알림 + 칩 "거래 종료", 목록에서는 빠져 있음 | 모의 응답 (종목 상태 변경)으로 10초 안 시험 |
| AC19 | 목록 | 행은 응답으로 받은 값만 씀 (시안 값은 예시) | 모의 응답에 종목 추가 후 나타나는지 |
| AC20 | 목록 스크롤 · 검색 | 행 높이 56px 고정, 목록 영역만 스크롤 (상한 없음) | 300개 이상에서 0.2초 넘는 멈춤 없음 (가상 스크롤 여지를 설계가 결정) |
| AC21 | 알림 + 목록 | `ratelimit`: "요청이 너무 많아 잠시 후 다시 시도합니다" + 남은 대기 시간 | 모의 429 시험, 대기 중 새 요청 없음 |
| AC22 | 차트 영역 | `candleerror`: 빈 차트 대신 문구 + [다시 시도]. 다른 종목을 누르면 정상 | 모의 응답 시험 |

| `--panel` | #181a20 | 말풍선, 상단 바 | 같음 (이전 문서의 #161a1e 는 오기였음, 파일 값으로 정정) | — |
| `--line` | #2b3139 | 테두리, 격자 | 같음 | — |

| `--up` | #0ecb81 | 상승 캔들, ▲ 등락 | 같음 (초록) | 약 8.2 : 1 |
| `--down` | #f6465d | 하락 캔들, ▼ 등락 | 같음 (빨강) | 약 4.9 : 1 |
| `--accent` | #f0b90b | 눌린 간격 글자·밑줄, 선택 행 막대, 마지막 가격 태그, 샘플 표시 | 같음 | 약 10 : 1 |
| `--warn` | #f0b90b | 재연결·요청 제한·데이터 없음 칩과 알림 | 같은 값 (`--accent` 와 동일 값이라 사실상 재사용) | 약 10 : 1 |
| `--err` | #ff8a3d | 연결 끊김·차단·거래 종료·목록 실패, 알림 테두리 | **새로 제안** | 약 7.4 : 1 |
| `--on-accent` | #1e2026 | 마지막 가격 태그 글자 | 같음 | 약 13 : 1 |

- 상승·하락은 **기호 + 색**으로 함께 쓴다 (▲ 초록 / ▼ 빨강). 캔들 모양은 몸통 색과 꼬리로도 구분된다.
- 대비 수치는 시안 색 값으로 계산한 근사치다. 설계 단계에서 도구로 한 번 더 확인한다.

### 글자와 간격

- 글자 크기: 종목 기호 17px(헤더)·14px(행), 현재가 24px(PC)·19px(모바일), 등락·알림·본문 13~14px, 눈금·거래대금 줄·바닥 문구 12px. 제품에서 12px 미만은 쓰지 않는다.
- 숫자는 모두 `tabular-nums` (가격이 바뀌어도 폭이 흔들리지 않게).
- 간격 단위: 4·8·12·16px. 목록 패널 안쪽 12px, 차트 여백 16px, 버튼 사이 8px.
- 모서리: 버튼·검색창 8px, 알림·말풍선 10px, 칩 999px(알약).

### 터치·접근성

- 목록 행 최소 높이 56px, 버튼·검색창·간격 버튼 44px 이상 (Android 기준 48dp 와는 제품 단계에서 맞춘다).
- 간격 버튼은 글자로 된 이름(1분 · 5분 …)을 가지며 `aria-pressed` 로 눌림을 알린다. 아이콘만 있는 버튼은 없다.
- 알림 줄과 상태 칩은 `role="status"`. 목록 검색창은 `label` 을 가진다.
- 움직임 줄이기 설정이 켜져 있으면 애니메이션을 끈다 (시안의 로딩 줄무늬는 정적).

## 6. 제안한 토큰 (기존 chart-only 에 없던 것)

- `--err: #ff8a3d` — 기존 색(상승 빨강과 구분하려고 주황). 이것만 새 값이다.
- `--warn` 은 시안 CSS 에 따로 적었지만 값은 `--accent` 와 같다. 제품에서는 한 토큰으로 줄여도 된다.
- 선택 행 배경은 `--seg` 를 재사용했다. 새 토큰 없음.

## 7. 시안의 한계 (제품 설계 때 확인할 것)

- **봉 개수**: 시안은 100개만 그렸다. 기획 AC1은 최근 500개. 500개면 봉 하나가 약 1.7px 폭이 되므로 확대·축소·스크롤 방식은 차트 라이브러리 선택(③ 단계)에서 정한다.
- **목록 개수**: 시안은 5개뿐이다. 실제 수백 개를 전부 그리는지, 보이는 줄만 그리는지(가상 스크롤)는 AC20 성능 시험 결과로 설계가 정한다. 시안 목록 스타일은 두 방식 모두에 맞다.
- **실시간 동작**: 가격 갱신, 목록 순서 변화, 재연결 채움, 24시간 연결 만료는 화면으로 보여 줄 수 없다. 시안은 "정상"과 "멈춤" 모습만 보여 준다.
- **정렬 기준의 실시간 변화**: 거래대금은 계속 바뀌므로, 실시간 중 행 순서가 움직일 수 있다. 열린 질문 2에서 정한다.
- **가짜 데이터**: 기호 `BTCUSDT`·`ETHUSDT`·`1000PEPEUSDT` 는 형태만 흉내 낸 예시다. 가격·거래대금·봉은 모두 임의 값이다. `OLDCOINUSDT`(거래 종료)·`SAMPLEUSDT`·`EXAMPLEUSDT` 는 시안 전용 이름이다.
- **기획 밖 상태 2개**: `empty`(목록 0개)와 `listerror`(목록 받기 실패)는 AC에 직접 없고 "화면 상태로 표시"하는 원칙에서 추가했다. 기획이 빼라고 하면 빼도 된다.
- **451 확인 전**: PR/FAQ 열린 질문 0번(한국에서 열리는지)은 아직 미확인이다. 그래서 `blocked` 상태를 기본 상태 목록에 넣어 두었다.

## 8. 열린 디자인 질문 (사용자가 정한다)

### 질문 1. 1000배 단위 종목 안내

- **A. 안내 표시 (시안 기본)**: 헤더에 "· 1000배 단위 종목", 행 거래대금 줄에 "· 1000배 단위". 기호가 `1000PEPEUSDT` 처럼 낯선 이유를 바로 알려 준다. PR/FAQ 추천과 같다.
- **B. 기호만**: 안내 문구 없이 바이낸스가 준 기호 그대로. 화면이 가장 단순하다. 바이낸스 응답에 단위 정보가 있는지 확인되지 않았다.
- 시안에서 B 로 바꾸려면 `renderHeader` 와 `renderList` 의 안내 문구 두 곳을 지우면 된다 (설계 전 결정 후 반영).

### 질문 2. 목록 행 순서 (실시간 중)

- **A. 열 때 정한 순서를 유지하고 값만 갱신 (추천)**: 행이 튀지 않아 누르기 쉽다. 새로고침 때만 거래대금 순으로 다시 정한다.
- **B. 실시간으로 거래대금 순 재정렬**: 항상 "지금 가장 많이 거래되는 순"이지만, 행이 자주 움직여 잘못 누를 수 있다.
- 이 시안은 A 가 되도록 그렸다 (예시 순서 고정). 열 제목 클릭 정렬은 이번 범위에 넣지 않았다 (기획 결정 2).

### 질문 3. 목록 행 정보 (거래대금 줄)

- **A. 거래대금 줄 표시 (시안 기본)**: 2줄 행 (기호·현재가 / 거래대금·등락). 정렬 기준이 눈에 보여 "왜 이 순서인지" 알 수 있다. 행 높이 56px.
- **B. 한 줄만 (기호·현재가·등락)**: 행 높이 40px 정도로 줄여 한 화면에 더 많이 보인다. 거래대금이 안 보여 순서 이유가 불분명하다.
- A 를 기본으로 두었다. 목록이 길어 한 화면에 많이 보이는 것을 원하면 B.
