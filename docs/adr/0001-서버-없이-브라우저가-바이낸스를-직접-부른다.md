# 0001. 서버 없이 브라우저가 바이낸스 공개 시세를 직접 부른다

- 날짜: 2026-10-29
- 상태: 제안
- 관련: `docs/03-tech-design.md` 4-0, 5절

## 맥락
시세 조회 전용 학습용 화면이다. 비밀값이 없고, 사용자 PC 브라우저에서 바이낸스 klines 응답이 정상으로 확인됐다. 클라우드 서버 IP 는 451 로 막힐 위험이 더 크다는 보고가 있다 (PR/FAQ 위험표).

## 결정
Vite + TypeScript + React 정적 앱으로 만들고, 브라우저가 `fapi.binance.com`(REST)·`fstream.binance.com`(WebSocket)을 직접 부른다. 실행은 내 PC 의 `npm run dev`.

## 고려한 대안
| 대안 | 고르지 않은 이유 |
|---|---|
| 로컬 중계 서버 (Node) | 응답 헤더 제약(CORS)은 풀리지만 실행할 프로세스가 하나 늘고 학습 범위 밖 |
| 클라우드 중계 / 배포 | 451 위험이 더 크고 운영 비용이 든다 |

## 결과
- 좋아지는 것: 비용 0, 실행 단순, 비밀값이 생길 자리가 없다.
- 감수하는 것: 브라우저가 읽을 수 있는 응답 헤더만 쓴다 (`Retry-After` 가 안 보이면 기본 대기). 요청 제한은 내 IP 하나 기준.
- 나중에 다시 볼 신호: 내 PC 에서도 451 이 나거나, 헤더를 못 읽어 요청 제한 처리가 부족할 때.
