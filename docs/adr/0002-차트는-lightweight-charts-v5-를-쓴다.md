# 0002. 차트는 TradingView Lightweight Charts v5 를 쓴다

- 날짜: 2026-10-29
- 상태: 제안
- 관련: `docs/03-tech-design.md` 4-0, 5절

## 맥락
캔들 500개 + 거래량 막대 + 십자선 말풍선(KST) + 확대·스크롤이 필요하다 (AC1, AC5). 학습 목적이 "차트 그리기 자체"는 아니다 (PR/FAQ 열린 질문 7 추천).

## 결정
Lightweight Charts v5 (Apache 2.0) 를 쓴다. 캔들 시리즈 + 거래량 막대 시리즈(별도 가격 눈금). 시각 표시는 차트의 시간 형식 함수에 KST 형식 함수를 넘긴다. 라이선스 조건대로 화면에 TradingView 표기·링크를 둔다 (차트의 표기 로고 옵션 + 바닥 문구). 정확한 옵션 이름은 설치 버전 문서로 확인한다.

## 고려한 대안
| 대안 | 고르지 않은 이유 |
|---|---|
| canvas 직접 그리기 | 확대·스크롤·눈금·십자선을 모두 만들어야 해 작업이 가장 크다 |
| 다른 차트 라이브러리 (ECharts 등) | 훨씬 크고, 금융 차트 기능은 Lightweight Charts 가 더 맞다 |

## 결과
- 좋아지는 것: 차트 기능을 거의 바로 얻는다. 실시간 갱신용 `update` 가 있어 봉 하나씩 반영이 가볍다.
- 감수하는 것: 의존성 1개, TradingView 표기 의무, 라이브러리 시간 형식(초 단위 UTC)에 맞춘 변환.
- 나중에 다시 볼 신호: 표기 의무를 원치 않거나, 차트 그리기를 직접 배우고 싶어질 때.
