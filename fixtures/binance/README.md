# 바이낸스 샘플 응답 (손으로 쓴 가짜 샘플)

이 폴더의 JSON 은 **실제 바이낸스 응답을 캡처한 것이 아니다.** 공식 문서 접속과 실제 네트워크 시험이
이번 단계에서 막혀 있어서, 바이낸스 응답 형식을 보고 손으로 쓴 샘플이다.

- 필드 이름·구조는 바이낸스 선물 공개 API 의 알려진 형식을 따른다 (`/fapi/v1/exchangeInfo`, `/fapi/v1/ticker/24hr`, `/fapi/v1/klines`, `!ticker@arr`, `<symbol>@kline_<interval>`).
- **상태 글자(`TRADING`, `BREAK`), 계약 종류(`PERPETUAL`)는 확인되지 않았다.** 샘플은 방어 시험용이다. 실제 값은 사용자 PC 에서 1회 받아 대조해야 한다 (03-tech-design 4-8).
- `SOMETHING_NEW` 같은 상태 값은 "모르는 값은 거래 중이 아님" 규칙을 시험하려고 일부러 넣었다.
- 가격·거래량 숫자는 임의 값이다.
